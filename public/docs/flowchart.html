Interactive Architecture Flowchart

End-to-End Cryptographic Lifecycle

Follow the data packets as an academic degree moves from registration to immutable Ethereum smart contract minting and public verification.

Client Ingestion STEP 01
🎓 Student Enrollment
Admin inputs student details (Name, Roll No, Department, Batch) into the secure client.
Hashing Engine STEP 02
🔑 SHA-256 Digest Derivation
Deterministic concatenation of student fields into a unique 256-bit cryptographic digest.
EIP-1193 Signer STEP 03
🦊 MetaMask Cryptographic Signature
Institution Admin signs the issueCertificate() transaction with private key.
EVM Execution STEP 04
📜 Smart Contract Ledger Commit
Solidity 0.8.19 contract enforces onlyAdmin check and seals record into state storage.
Consensus STEP 05
⛓️ Block Mining & Finality
Ganache/Ethereum network mines the block, producing an immutable transaction receipt.
Bridge STEP 06
📱 Dynamic QR Code Embedding
SVG/Canvas generates physical bridge QR code containing the direct public verification link.
Public Attestation STEP 07
🔍 Zero-Trust Verification
Employers or embassies verify authenticity instantly by scanning QR or querying hash.
